# 手機訊息 (MsgBox)

從 deskctl 專案抽出的「手機訊息資料庫」, 獨立成一個 App (套件名稱 `tw.msgbox`, 可與舊 App 並存)。
把通知收錄到本機 SQLite, 可依 App → 對話 → 訊息串瀏覽、搜尋、只看未讀, 並有 2x2 桌面小工具。

## 檔案 (android/app/src/main/java/tw/msgbox)
| 檔案 | 作用 |
|---|---|
| NotifListener.kt | 通知監聽服務, 轉給 MsgCapture |
| MsgCapture.kt | 過濾通知 (常駐/進度/媒體/群組摘要) 並寫入資料庫 |
| MsgDb.kt | SQLite (msgs.db) 存取層 |
| MessagesActivity.kt | 主畫面 (三層瀏覽) |
| SettingsActivity.kt | 新增: 通知存取狀態、收錄開關、App 白名單、保留天數 |
| Widgets.kt | 2x2 小工具 |
| Prefs.kt / AppLog.kt / AppPicker.kt | 設定 / 記錄 / 選 App 對話框 (皆已精簡) |

## 與原專案的差異
- 移除: 藍牙橋接、控制器轉發 (MessageFeature/MsgBus)、其他小工具、無障礙服務、開機自啟、前景服務與相關權限。
- 設定檔改名 `msgbox` (原 `deskctl`), 資料庫檔名仍為 msgs.db 但存在新 App 自己的資料夾, **不會自動帶入舊資料**。
- 沿用同一把 debug.keystore 與 GitHub Actions 流程 (`.github/workflows/build-apk.yml`), 推上 GitHub 即可打包 APK。
- 尚未在 Android SDK 環境實際編譯 (此環境沒有 SDK); 已逐一檢查所有符號引用皆存在。

## v1.1 新增與優化
- **釘選**: 長按 App 可釘選 (排最前); 長按對話 (或對話畫面右上 ⋯) 可釘選, 釘選的對話顯示在首頁最上方「📌 釘選」。
- **忽略來源**: 長按對話/訊息 → 「忽略此來源」。被忽略的來源不顯示 (清單、搜尋、未讀數、小工具), 之後也不再收錄; 舊訊息保留。
  在該 App 頁的「此 App 設定 → 已忽略的來源」點一下找回, 或「全部找回」。App 只剩被忽略來源時首頁仍會列出, 才找得回來。
- **效能**: 資料庫讀寫全在背景執行緒; 取代 1.5 秒輪詢, 改由資料變動事件通知重繪 (200ms 合併); 搜尋打字停 250ms 才查;
  對話名稱寫入時正規化 + 索引 (pkg,conv)、未讀部分索引; 啟用 WAL; 對話清單一次查詢帶出最新訊息 (去掉 N+1)。
- 資料庫結構為 v1 (新增 pins / ignored 兩張表)。

## v1.1.1 修正: Instagram 分不出不同人
Instagram 的通知「對話標題」是自己的帳號 (如 3km.day)、標題是「3km.day: Eason Wang」, 所有人被歸成同一個對話。
現在若標題以「對話標題: 」開頭, 就以冒號後面的人當對話; 對話內不再重複顯示「帳號:」前綴。
資料庫升到 v2, 開啟時會自動把舊資料依同樣規則重新分開 (不會刪除任何訊息)。

## v1.2.0 聊天畫面擷取 (實驗性) + 對話氣泡
- 新增 `ChatAccess` 無障礙服務: 讀你勾選的聊天 App 畫面, 把「我送出的訊息」(靠右氣泡) 記進資料庫 (欄位 `mine`, DB v3)。
- 對話畫面改成聊天氣泡: 對方靠左 (白底)、我靠右 (淺藍底); 對話清單預覽會顯示「我: …」。小工具與未讀數不含我的訊息。
- 預設關閉。設定 → 「聊天畫面擷取」: 啟用、選 App、前往系統無障礙、除錯輸出、查看/複製記錄。
- 判斷規則 (ChatAccess.isMine): 有輸入框才算聊天畫面; 標題列以下、輸入框以上、右邊緣 >= 86% 螢幕寬 = 我的氣泡; 排除「已讀/Seen/時間」。
  新訊息以「拼接比對」判斷: 只記接在已知清單尾端的內容; 進入對話當下看到的歷史不記, 往上捲再捲回來不會重複。
- 已知限制: 每個 App 畫面結構不同, 規則可能要依 App 微調 (用「除錯」輸出文字位置); 進入對話時畫面上沒有我的訊息、
  接著第一則送出的訊息會漏記; 記錄的時間是偵測到的時間, 不是實際送出時間。

## v1.3.0 介面與使用體驗
- **標題列重做**: 返回 + 完整標題 (最多兩行) + 副標題, 操作全收進 ⋮ 選單 (依所在層級顯示可用項目); 標題不會再被按鈕擋住。首頁另有 ⚙ 設定。
- **清單**: 每列 = 頭像 (App 用圖示、對話用名字首字圓形頭像) + 名稱 + 最新一則預覽 + 時間 (今天 HH:mm / 昨天 / M/d) + 未讀數徽章; 釘選以 📌 標示。
- **搜尋列**: 圓角、含清除鈕, 進入對話後自動隱藏; 開啟時不再自動彈出鍵盤。
- **捲動**: 內容更新時保持位置; 在對話底部時自動跟著新訊息; 換頁才回頂端。
- **空狀態**: 沒訊息/搜尋無結果/來源全被忽略時顯示說明與按鈕。
- **視覺**: 狀態列與導覽列與頁面同色、卡片輕微陰影、點擊水波紋、文字按鈕取代厚重按鈕、設定頁加上返回標題列。
- 共用元件在 `Ui.kt`。尚未做深色模式。

## v1.4.0 聊天畫面擷取: 同時記錄對方訊息
- 開著聊天時對方傳來的訊息 App 不會跳通知, 通知收錄抓不到 → `ChatAccess` 現在也讀靠左的氣泡記為「對方」(設定可關)。
- 與通知收錄去重: 最近 5 分鐘內相同內容的對方訊息不重複記錄; 群組聊天氣泡上方的寄件人名稱標籤會被濾掉。
- 拼接比對改成比對「(我/對方, 文字)」序列, 進入對話時畫面上有對方訊息就有基準, 「第一則送出的漏記」的情況減少。
- 除錯輸出 (設定 → 聊天畫面擷取) 新增: 每個節點標示 [我]/[對方]/[描述]; 沒有文字但有描述的節點也會列出, 方便找出 App 把訊息放在哪。
- 已知限制: 圖片/貼圖/語音沒有文字, 讀不到; 畫面上的引用回覆、連結預覽標題可能被誤當成訊息 (用除錯輸出回報後可針對 App 調整)。

## v1.5.0 修正 Messenger 擷取
- Messenger 把訊息的畫面文字寫成「寄件人, 內容, double tap to see…」: 現在拆出寄件人與內容, 說明文字不再存進資料庫; 寄件人是「我的名字」(設定) 或 You/你 → 我, 否則 → 對方。
- 濾掉「You replied to Roxy / Replying to Roxy」回覆標籤, 以及標籤後面那則被引用的原文。
- 同一則訊息被畫面重複描述 (文字節點 + 說明節點) 時只記一則。
- 合併比對加強: 邊界對不上時改用已知清單最後幾則當錨點, 連續傳送多則不再只記到一則。
- 設定: 新增「我的名字」欄位; 對話 ⋮ 選單新增「清除畫面擷取的訊息」(只刪擷取的, 通知收錄的保留)。
- 資料庫 v4: 升級時自動清理舊版擷取的雜訊 (去掉 double tap 說明與寄件人前綴、刪除 Replying to 標籤)。舊版誤記的「被引用原文」無法自動辨識, 可用「清除畫面擷取的訊息」。
- 除錯輸出 (設定 → 聊天畫面擷取) 每列加上節點類別與 id、完整文字 (到 120 字), 並標示 [列:寄件人] / [引用] / [標籤] / [我] / [對方] / [略過]。
